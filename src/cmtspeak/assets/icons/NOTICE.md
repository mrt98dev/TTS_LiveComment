# Icons

The SVG icons in this directory are original, hand-authored minimal line
icons (24x24 viewBox, `currentColor` for fill/stroke so `ui/theme.load_icon`
can recolor them at runtime). They are not copied from any third-party icon
set — they follow the same general visual convention as common open-source
icon sets (simple strokes, rounded caps) but the path/shape data here is
original to this project.
